## Notes / 笔记

### Sigmoid vs Softmax

虽然它们确实都把原始数值（Logits）“挤”到了 0 到 1 之间来表示概率，但它们的核心区别在于：**“要不要跟别人竞争”。**

一句话概括：**Sigmoid 是一场“单人考核”（互相独立），而 Softmax 是一场“零和博弈”（必须争抢有限的 100% 份额）。**

#### 1. 机制区别：独立 vs 互斥

| 特性 | Sigmoid | Softmax |
| --- | --- | --- |
| **关注点** | **只看自己**。它的计算只依赖于当前的单个数值。 | **顾全大局**。它需要把所有的数值都拿过来，计算总和后再分配比例。 |
| **总和规则** | 多个输出值的总和**不一定等于 1**（可能三个输出都是 0.9）。 | 所有输出值的总和**必须严格等于 1**。 |
| **数学公式** | $S(x) = \frac{1}{1 + e^{-x}}$ | $S(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}$ (分母是所有项的指数和) |
| **通俗比喻** | 问卷里的**多选题**（你可以同时勾选 A、B、C） | 问卷里的**单选题**（你选了 A，就不能选 B） |

#### 2. 场景区别：实战中怎么选？

**场景 A：使用 Sigmoid (多标签分类 / 二分类)**

假设你要判断一张图片里的动物属性。模型最后输出 3 个节点代表：是猫吗？是黑色的吗？毛茸茸的吗？

- 经过 Sigmoid 后，输出可能是：`[0.9, 0.8, 0.95]`
- **含义：** 它有 90% 的概率是猫，80% 的概率是黑色的，95% 的概率是毛茸茸的。
- **结论：** 属性之间**互不冲突**。它完全可以同时是一只黑色的、毛茸茸的猫。

**场景 B：使用 Softmax (多分类)**

假设你要判断一张图片到底属于哪种动物。模型最后输出 3 个节点代表：是猫？是狗？还是猪？

- 如果用 Sigmoid，可能输出 `[0.9, 0.8, 0.1]`（90%像猫，80%像狗，不合逻辑）。
- 经过 Softmax 后，输出会被强制按比例挤压，变成：`[0.7, 0.25, 0.05]`
- **含义：** 它有 70% 的概率是猫，25% 的概率是狗。
- **结论：** 类别之间是**互斥**的。猫的概率变高了，狗的概率就必然被挤压变低。

#### 3. 它们在深度学习网络中的位置

- **Sigmoid** 早期经常被用在网络的隐藏层（作为激活函数），但因为容易造成**梯度消失**（当输入值太大或太小时，导数几乎为0），现在隐藏层大多换成了 ReLU。它现在主要退居到**二分类/多标签任务的最后一层**。
- **Softmax** 几乎永远只出现在网络的**最后一层**（或者 Attention 机制里用来计算权重分配），专门用来把数值转化为标准的概率分布，交由 Cross-Entropy Loss 计算误差。
